# iPhone.Duo.E-Reader
a swift app designed for reading EPUBs on iPhone Duo with a clean display and external cover photo

this is my first GitHub repo AND my first Xcode app so my only plan with this is to make a nice clear app

# the plan
I want to have an importer to import EPUBs but also to convert docx and pdf files to EPUB so the can work too.
the app should be easy to use with important features like page animations and save points.
most importantly it needs to display the book cover on the external display and the table of contents when closed.
